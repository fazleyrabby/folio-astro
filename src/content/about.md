# About Me

I'm a full-stack developer with a passion for building software that solves real problems. I specialize in web applications — from crafting clean APIs to shipping polished user interfaces.

My journey into development started with curiosity and a broken laptop in 2019. Since then, I've worked with startups, agencies, and enterprise clients across multiple industries.

## What I Do

I focus on the intersection of **good engineering** and **great user experience**. I believe code should be readable, systems should be maintainable, and products should be a joy to use.

When I'm not coding, I'm probably reading about distributed systems, tinkering with new frameworks, or convincing myself I need another mechanical keyboard.

## Values

- **Simplicity over cleverness** — code is read more than written
- **Ship early, improve often** — done is better than perfect
- **Empathy in engineering** — the best software is built with users in mind
