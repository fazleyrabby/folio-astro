# Uses

A living document of the hardware, software, and tools that make up my daily development setup.

## Editor & Terminal

- **VS Code** — Primary editor with minimal extensions
- **iTerm2** — Terminal emulator with zsh
- **Oh My Zsh** — Shell framework with custom aliases
- **JetBrains Mono** — Monospace font for code

## Hardware

- **MacBook Pro 14"** (M3 Pro) — Main machine
- **LG 27" 4K Monitor** — External display
- **Keychron K2** — Mechanical keyboard (brown switches)
- **Logitech MX Master 3** — Mouse

## Development Stack

- **Node.js + TypeScript** — Backend services
- **React / Astro** — Frontend frameworks of choice
- **PostgreSQL** — Primary database
- **Docker** — Local development environments
